# Lesson page template

## Subtitle

Zones, backplane nets and drawing marks from page standard v{version}. Nothing to build.

## Labels

- gutter: Bus B gutter
- build_zone: Build zone · tape lanes, parts and test points
- switch: Fold switch (optional)
- schematic: Schematic
- schematic_note: same labels as the parts

## Workbook

- Predict: What will happen, and why?
- Measure: Write the readings at each test point.
- Explain: Did it match? What surprised you?

## Drawing marks

- Lane: lay 5 mm copper tape here, one piece per run
- Corner: fold along the crease; never cut
- J  Joint: cut, overlap 10 mm, solder
- X  Crossing: insulating patch before the upper strip
- TP  Test point: put a meter probe here
- R  Resistor: ¼ W, actual size, across a 10 mm gap
- LED: + marks the anode, the long leg
- D  Diode: the band marks the cathode
